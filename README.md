# 📊 Real-Time Job Market Analytics Dashboard

An interactive Data Analytics project built using **Python, MySQL, and Power BI** to analyze global job market trends, salary distributions, work modes, and hiring patterns.

---

## 🚀 Project Overview

This project demonstrates an end-to-end Data Analytics workflow, including:

- Data Cleaning using Python
- Exploratory Data Analysis (EDA)
- SQL-based Business Analysis
- Interactive Dashboard Development in Power BI
- Business Insight Generation

The dashboard enables users to explore salary trends, experience levels, company sizes, work modes, and hiring distribution across countries.

## 📈 Dashboard Features

- KPI Cards
  - Total Jobs
  - Average Salary
  - Total Job Titles
  - Total Countries

- Average Salary by Experience Level

- Job Distribution by Work Mode

- Top 10 Highest Paying Job Titles

- Average Salary by Company Size

- Job Opportunities by Country

- Employment Type Distribution

- Interactive Slicers

---

## 📊 Key Insights

- Executive-level professionals receive the highest average salaries.
- Medium and large companies generally offer higher salaries.
- Remote, Hybrid, and On-site job trends can be analyzed interactively.
- Full-Time employment dominates the job market.
- Hiring opportunities are concentrated in a few major countries.
